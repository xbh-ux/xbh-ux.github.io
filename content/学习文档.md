# 2026.8.10 — 2027 春节（2027.2.6 除夕，2.7 大年初一）分阶段学习清单

总周期：180 天，分为 5 大阶段，贴合你空闲上班摸鱼 + 晚上虚拟机实操，
全部对标尹正杰博客、深圳云原生运维跳槽涨薪目标（8k→13k~16k）

核心主线：监控差异化优势（Categraf/N9E）→ K8s 生产深度（网络 / 存储 / 故障）→ 自动化交付（Ansible/Helm/GitOps）→ 中间件排障 + 代码基础 → 项目复盘 + 简历打磨（过年前直接准备跳槽）

配套环境：3 台 Ubuntu 虚拟机集群，全程动手实操，拒绝只看文档

## 阶段一：8.10 ~ 9.10

目标：独立搭建完整企业监控平台，简历第一个重量级项目，市面绝大多数运维只会 Prometheus，Categraf + 夜莺是你的竞争优势

### 每日固定安排

上班空闲 2h：读尹正杰监控系列博客、整理配置模板、记录报错踩坑笔记

晚间 1.5h：3 节点虚拟机实操部署、调通全链路

### 月度细分任务

1. 第 1-10 天：Categraf 全量吃透
    
    - 部署 DaemonSet 模式 Categraf，开启 node/cadvisor/kube-state 三类核心采集插件
    - 配置 MySQL、Redis 自定义采集；掌握 remote_write 推送协议、指标过滤、标签改写
    - 实操：Categraf 采集容器日志，替代 Filebeat，统一日志 + 指标采集
    
2. 第 11-20 天：VictoriaMetrics 单机 + 简易集群部署
    
    - 对比原生 Prometheus，掌握 VM 高压缩、高并发优势
    - 配置 vmagent 做指标转发，实现多集群指标汇总
    
3. 第 21-30 天：N9E 夜莺单机 + 3 实例高可用集群（核心）
    
    - 部署共享 MySQL/Redis 的 N9E 集群，Nginx 负载均衡接入
    - 对接 Categraf 指标，自定义 Grafana 大盘、钉钉告警规则、告警屏蔽 / 分组
    - 完整闭环验收：机器 CPU / 内存异常自动触发告警，指标长期存储无丢失
    

### 阶段产出

完整监控架构文档、可复用 Categraf/N9E 一键部署脚本、个人实操排坑笔记（直接写进简历项目）

## 阶段二：9.11 ~ 10.31

目标：摆脱只会搭集群，吃透企业生产网络、存储、调度、故障排查，对应磐匠平台运维真实场景

### 模块 1：Calico 网络深度（20 天，博客重点内容）

1. Calico 三种模式 IPIP/VXLAN/BGP 完整部署对比
2. Pod 固定节点网段、NetworkPolicy 网络隔离策略、LoadBalancer 本地负载均衡
3. 故障演练：Pod 跨节点不通、外网访问失败、端口拦截、路由异常排查

### 模块 2：云原生存储全栈（15 天，你之前学习的 LocalPV 延伸）

1. Local-path 本地存储、OpenEBS CSI 持久化存储、StorageClass 动态供给
2. StatefulSet 部署 MySQL 集群，PV 扩容、数据备份恢复
3. MinIO 分布式对象存储部署，对接业务静态资源

### 模块 3：集群运维 + 故障复现（16 天，面试拉分点）

1. 集群生命周期：master 节点扩容、worker 增减、v1.31 版本平滑升级、ETCD 备份与故障恢复
2. 资源调度：污点容忍、节点亲和、GPU 调度、QoS 驱逐策略、HPA 自动扩缩容
3. 高频故障复现演练（必须亲手复现并修复）：
    
    Pod CrashLoopBackOff、镜像拉取失败、证书过期、磁盘 IO 打满、API-server 限流

## 阶段三：11.1 ~ 12.10

目标：实现基础设施即代码，掌握企业标准化发布流程，简历第二个完整实战项目

### 1. Ansible 自动化（15 天，博客大量实战）

- Inventory 清单、Playbook/Role 标准化；一键初始化服务器、批量部署 K8s 集群
- 实操：用 Ansible 脚本自动化搭建你现有的 3 节点 K8s，替代手动敲命令

### 2. Helm 应用打包（10 天）

- 编写自定义 Helm Chart，环境隔离、参数复用、版本回滚；Harbor 私有镜像仓库对接

### 3. GitOps CI/CD 流水线（15 天，深圳云原生岗硬性要求）

- GitLab CI：代码提交自动构建镜像、镜像安全扫描
- ArgoCD 实现 GitOps：代码仓库变更自动同步部署 K8s、灰度发布、一键回滚

### 阶段产出

全套自动化部署脚本、完整 GitOps 发布流程文档

## 阶段四：12.11 ~ 1.20

目标：补齐业务对接能力，简单代码赋能运维，和纯集群运维拉开差距

### 模块 1：主流中间件运维（20 天，面试必问）

1. MySQL：主从复制、慢 SQL 排查、索引优化、锁问题、高可用 MGR 集群基础
2. Redis：缓存穿透 / 雪崩解决方案、集群扩容、持久化故障
3. RocketMQ：消息堆积、死信队列、集群高可用排查

### 模块 2：运维必备代码（21 天，不用精通，够用即可）

1. Shell 进阶：三剑客 awk/sed/grep，独立写巡检、备份、告警自动化脚本
2. Python 运维基础：requests 接口调用、批量服务器信息采集、简单巡检工具
3. Go 基础巩固：看懂 Categraf 简单源码，写小型自定义指标采集脚本（你已有 Go 环境）

## 阶段五：1.21 ~ 2.5

距离除夕 2.6 仅剩两周，停止新知识学习，全力转化已有能力用于求职

1. 整理两大完整实战项目（监控平台、GitOps 自动化集群），梳理项目架构、解决的业务痛点、个人落地成果，量化优化数据（存储成本、运维效率提升）
2. 简历优化：把 180 天实操全部转化为岗位匹配话术，突出 Categraf/N9E、Calico、GitOps 差异化技能
3. 故障面试模拟：自己复现的 30 + 种 K8s 故障，梳理标准排查思路，练习口述回答
4. 背调 & 谈薪准备：梳理薪资谈判话术、流水规避方案、深圳运维岗位薪资区间调研
5. 查漏补缺：回看前四个阶段薄弱知识点，快速补全短板


# 关键避坑提醒

1. 全程优先实操，不要只看文章不搭环境，面试只问落地踩坑经验
2. 优先吃透监控体系，这是你跳槽最大差异化优势，普通 K8s 运维竞争内卷严重
3. 所有产出（脚本、文档、排坑笔记）全部留存，直接复用进简历，不用临时编造项目
4. 不分散精力学习无关技术（老旧 Zabbix、纯 Windows 桌面运维等），全部聚焦深圳云原生平台运维招聘需求
