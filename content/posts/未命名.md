# 完整实现：自动订阅下载 + 局域网手机流畅播放 + 看完自动删

基于你 SER5 Max + PVE + 内置 2T SATA 固态 + LXC Ubuntu Docker 方案，全程内置硬盘无 USB 掉盘，核显硬解保证手机不卡顿，搭配脚本实现观影后自动清理。

## 一、整套组件分工（全部 Docker 部署在同一 LXC）

1. **Jellyseerr**：手机 / 浏览器选片订阅（你提交想看的电影 / 剧集）
2. **Radarr (电影) / Sonarr (剧集)**：自动搜资源、推送下载、管理媒体库
3. **qBittorrent**：后台下载，硬链接入库，不重复复制文件
4. **Jellyfin**：局域网串流，AMD Vega8 核显硬解，手机 4K 流畅无缓冲
5. **定时清理脚本**：识别「已看完」影片，N 天自动删除释放硬盘空间
