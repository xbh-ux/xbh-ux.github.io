# 这是我的第一篇文章
为什么要写这个文章，是因为原来的我都是使用的hexo主题+git手动进行上传的文章，最近使用obsidan做笔记，完整的插件生态让我彻底爱上了这个软件，就琢磨这能否将手动上传更改为自动上传。

## 缺陷
```bash
1.有着将近2~3分钟的延迟，根据你实际的网速来
2.使用的obsidian git插件必须开启翻墙工具，因为国内有时无法访问github仓库
```
